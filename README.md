# NodeSight

See what every herb and ore on your minimap is, with an arrow to the nearest one and gold sparkles on it when you're close.

A World of Warcraft addon for WoW Forever.

## Install

Get it from [CurseForge](https://www.curseforge.com/wow/addons/node-sight), or download this repository and put its files in a folder named `NodeSight` inside `Interface/AddOns`.

## Files

- `NodeSight.lua`: the whole addon. It opens with an overview and a list of its parts.
- `NodeSight.toc`: tells the game what to load.
- `Bindings.xml`: the key binding that turns the minimap symbols on and off.
